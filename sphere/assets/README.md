# Help illustration and artwork

`classic-board.png` shows Hexsweeper's own Classic board, rendered from
`bounded.html` with the Small board setting. The blue and green numbers count
nearby mines; the red mark is a flag. Luke Steuber created this screenshot on
September 15, 2026. It is original project artwork covered by the repository's
[MIT license](../../LICENSE).

The identical copy in `sphere-ux/assets/` serves the experimental Help pages.
Collection exports embed the image; the web and app exports use their local
asset copy. The Help link to the history of Minesweeper is further reading;
the illustration depicts Hexsweeper.

SHA-256: `a87ad40e61ecffb502e444e197f2a74bb0c42214b6c356c7a1aea625b516031f`.

Globe textures have their own [source and license notes](textures/README.md).
Keep those notices when redistributing the textures. The repository's
`fonts/OFL.txt` covers the bundled IBM Plex fonts.
